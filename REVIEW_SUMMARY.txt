PROBLEM:
  Trust-weighted aggregation is 52 reward points WORSE than naive aggregation.
  This contradicts your hypothesis that trust defense should help.

ROOT CAUSE (3 Most Likely):

  1. B1 NOT MARKED AS SUSPICIOUS (40% probability)
     • Spillback detection failing
     • B1 trust score not dropping below 0.5
     • Aggregation weights not differentiating agents
     
  2. QUADRATIC PENALTY TOO AGGRESSIVE (35% probability)
     • B1 downweighting: 0.3² = 0.09 (removes 91%)
     • Other 8 agents cannot compensate
     • Overall performance drops
     
  3. AGENT ID MISMATCH (15% probability)
     • Episode data uses "B0" but trust scores use different naming
     • Trust weights applied to wrong agents
